# Последние годы Константинополя

Пошаговая историческая стратегия в браузере. Вы — император ромеев в 1444–1453 годах. Готовьте город к неизбежной осаде Мехмеда II.

**Играть:** https://craidenx.github.io/byzantium-game/

## Что внутри

- 124 события: исторические (Варна, смерть Иоанна VIII, Румелихисар, уния в Святой Софии, Урбан, Джустиниани) и случайные — с короткими историческими пояснениями.
- Семь ресурсов: казна, стены, гарнизон, помощь Запада, единство, османская угроза, Морея.
- Три сложности (Сон, Реальность, Кошмар) и три темпа (Хронограф — полгода, Сказание — сезон, Летопись — два месяца).
- Осада в четыре этапа, концовки, эпилоги «Судьба империи» и итоги правления.
- Исторический зал с портретами, достижения, военный совет, возвращение в прошлое.
- Музыка и звуки синтезируются прямо в браузере.

Вся игра — один файл `index.html`, без сборки и внешних библиотек. Прогресс сохраняется в браузере.

Для разработчика: добавьте к адресу `#dev`, чтобы открыть панель со скрытыми числами, вызовом любого события и справочником.
